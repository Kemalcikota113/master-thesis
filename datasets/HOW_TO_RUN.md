## How to run documentation

This is a small documentaiton just showing how to spin up and run every dataset and check out its features.

## **1. todomvc-es6**

`cd datasets/todomvc-es6 && npm run dev`

## **2. framework-bench**

`cd datasets/framework-bench && npm run dev`

## **3. realworld-js**

This datasets requires 2 terminal windows in order to spin up the frontend separatly from the backend.

*Terminal 1:*

`cd datasets/realworld-backend && npm run dev`

*Terminal 2:*

`cd datasets/realworld-backend && npm run dev`
